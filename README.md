# CHT 同仁服裝配色展示

三種顏色、四款圖案、兩種衣型，共 24 組搭配，支援放大檢視與 PNG 下載。

- 顏色：23 白色、11A 藏青、39 淺紫。
- 圖案：A 款海地星空、B 款胸章款、C 款通路 SI LOGO、D 款海地星空 LOGO。
- 衣型：T-shirt、POLO 衫。
- 預設：23 白色、A 款、T-shirt。

線上展示：https://ethanzhung.github.io/cht-team-wear/

本機預覽：於此資料夾執行 `python -m http.server 8765 --bind 127.0.0.1`，開啟 http://127.0.0.1:8765/ 。

所有預覽圖位於 assets/collection；catalog.json 記錄圖案、衣型、色號、實際尺寸及內容雜湊。頁面、放大與下載使用相同的 PNG 原圖。
